# Facts verified against these anchors
# - 8.5.11 (like 8.4.26) has NO php_rinit_session_globals() call in
#   MULTIPART_EVENT_START; the public fix adds it there (fix.patch).
# - php_session_send_cookie() returns FAILURE before the PS(send_cookie) = 0
#   assignment when SG(headers_sent) is set, so send_cookie stays 1.
# - The leaked bytes come from php_url_encode_impl()/zend_string_safe_alloc()
#   inside send_cookie, not from the warning text.
# - 8.5.11 shifts: send_cookie -53 lines, reset_id +42, rfc1867 -43/-41,
#   MULTIPART_EVENT_* -43/-44; SAPI +18, url safe_alloc +85.
#   The 8.5.11 heap/geometry constants are nevertheless unchanged
#   (HTDATA=chunk+0x690d8, 841 fillers, a0443/16, 6x(31,31) pads);
#   only the libphp symbol offsets differ (see metadata.txt).
